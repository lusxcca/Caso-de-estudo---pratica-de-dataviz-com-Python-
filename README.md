<h1>Projeto de Prática em Visualização de Dados com Python</h1>
Este é um projeto simples desenvolvido para praticar comandos de manipulação e visualização de dados em Python, utilizando um dataset de vendas de uma empresa.<br/><br />
📌 Objetivo
  Praticar conceitos fundamentais de análise de dados com Python, incluindo:

  &emsp;-Importação e exploração de datasets

  &emsp;-Limpeza e transformação de dados

  &emsp;-Filtros e agrupamentos

  &emsp;-Criação de gráficos estatísticos

  &emsp;-Criação de novas colunas com regras de negócio
   <br/><br/>
      <br/><br/>

📁 Estrutura do Projeto
O arquivo contém um notebook com as seguintes etapas:

&emsp;1.Importação das bibliotecas: pandas, numpy, matplotlib, seaborn

&emsp;2.Carregamento dos dados: leitura de um arquivo CSV de vendas

&emsp;3.Análise exploratória: formato, colunas, dados faltantes, estatísticas descritivas

&emsp;4.Operações básicas: soma, média, multiplicação de colunas

&emsp;5.Filtros: seleção de dados por categorias e condições combinadas

&emsp;6.Agrupamentos: médias, somas e estatísticas por categoria

&emsp;7.Gráficos diversos:<br/>
 &emsp;&emsp;Barras, histogramas, pizza, dispersão, boxplots

&emsp;8.Criação de coluna: classificação de clientes como VIP ou NÃO VIP

&emsp;9.Análise temporal: extração de informações de data

&emsp;10.Comparações finais: análise de vendas por status de cliente e categoria
